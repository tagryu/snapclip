## 훅의 심리학

### 훅이 해야 할 2가지
1. **Topic Clarity** — 영상이 뭐에 대한 건지 즉시 이해
2. **On-target Curiosity** — 계속 볼 이유 제공 (궁금증)

### 4대 훅 실패 원인
1. **Delay(지연)** — 너무 늦게 본론에 들어감
2. **Confusion(혼란)** — 뭔 말인지 못 알아들음
3. **Irrelevance(무관함)** — 타겟 관객에게 안 맞음
4. **Disinterest(무관심)** — 궁금증 유발 실패

### Curiosity Loop (궁금증 루프)
```
맥락 제공 → 새로운 질문 발생 → 추가 맥락 → 또 새로운 질문 → ...
```
- 시청자의 뇌에 "질문"을 심으면 답을 알 때까지 못 떠남
- **Open Loop**: 질문을 열고 → 최대한 늦게 닫기
- "절대 하지 마세요..." → 뭘? → 계속 시청

## 고전환 훅 공식 10가지

### 1. Contrast Hook (대비 훅) ⭐ 최강
```
"[일반적 믿음 A] vs [당신의 대안 B]"
```
- 예: "여드름 해결에 아큐테인이 최고라고? 이 허브가 3배 빠릅니다"
- A=기존 상식, B=새로운 관점
- **Stated Contrast**: 직접 비교 명시
- **Implied Contrast**: 암묵적 비교 ("이걸 모르면 손해")

### 2. Challenge Hook (도전 훅)
```
"[숫자]일 동안 [행동]했더니 이런 결과가"
```
- 예: "30일 동안 매일 얼음물에 세수했더니"
- 변화/여정 스토리에 최적

### 3. Question Hook (질문 훅)
```
"[타겟]이 [문제]를 해결하려면?"
```
- 예: "왜 당신의 옷이 비싸 보이지 않는 걸까?"
- 시청자가 자기 문제로 인식하게 만듦

### 4. Shock/Controversy Hook (충격 훅)
```
"[반직관적 주장]"
```
- 예: "비싼 옷 사지 마세요. 이유를 알려드릴게요"
- 기존 상식에 도전 → 호기심 폭발

### 5. List Hook (리스트 훅)
```
"[카테고리]에서 이 [숫자]가지만 기억하세요"
```
- 예: "2025년 봄 코디, 이 3가지면 충분합니다"
- 명확한 기대치 설정

### 6. Visual Shock Hook (시각 충격)
```
[예상 못한 비주얼로 시작]
```
- 상품의 극적인 변화 장면
- Before/After의 극단적 대비
- 📌 **AI 영상에서 가장 구현하기 좋은 훅**

### 7. Story Hook (스토리 훅)
```
"[구체적 상황/인물]이 [예상 못한 결과]를 만들었다"
```
- 예: "이 브랜드가 $30M을 번 비결"
- 뇌는 사실보다 스토리를 63% 더 잘 기억

### 8. Social Proof Hook (사회적 증거)
```
"[큰 숫자]명이 이미 [행동]하고 있습니다"
```
- 예: "품절 5회, 재입고 1분 만에 완판"
- FOMO(놓칠까 봐 두려움) 자극

### 9. "You" Hook (2인칭 훅)
```
"당신의 [문제]를 [시간] 안에 해결합니다"
```
- "나/우리" 대신 **"당신/여러분"** 사용
- 시청자가 자기 이야기로 느끼게

### 10. Agitation Hook (자극 훅)
```
"[고통점]이 해결 안 되는 진짜 이유"
```
- 고통을 자극한 뒤 해결책 제시
- 예: "옷을 잘 입는데도 촌스러워 보이는 이유"

## SnapClip 적용 — AI 훅 자동 생성 규칙

### 상품별 훅 매핑
| 카테고리 | 추천 훅 타입 | 예시 |
|----------|------------|------|
| 패션/의류 | Contrast + Visual | "이 가격에 이 핏? 직접 확인하세요" |
| 뷰티/스킨케어 | Before/After + Challenge | "7일 후 피부가 달라졌습니다" |
| 전자제품 | Comparison + List | "이 기능 하나가 10만원 더 비싼 제품을 이깁니다" |
| 식품 | Story + ASMR | "이 한 입에 반하지 않으면 환불" |
| 홈/리빙 | Problem-Solve + Visual | "이 지저분한 방이 5분 만에 변했습니다" |

### AI 카피 생성 시 규칙
1. **첫 문장 = 6단어 이내** (빠른 읽기)
2. **"당신/여러분" 사용** (2인칭)
3. **숫자 포함** (구체성)
4. **능동태 사용** (수동태 X)
5. **6학년 수준 어휘** (쉽게)
6. **질문 or 대비로 시작** (궁금증)

### 텍스트 훅 시각 규칙
- 크기: 64px+ (화면의 1/3 차지)
- 색상: 배경과 강한 대비 (빨강/노랑 키워드 하이라이트)
- 위치: 화면 중앙 또는 상단 1/3
- 시간: 0-2초 내 등장
- 애니메이션: 팝업 or 타이핑 (슬로우 페이드 X)
