# 🎨 템플릿별 상세 스펙

> 영상 생성 파이프라인이 직접 참조하는 템플릿 설계 스펙
> 각 템플릿의 모션, 텍스트, 음악, 타이밍을 정의

---

## 1. Simple (심플)

### 컨셉
깔끔하고 정보 전달 중심. Text-First 패턴 기반.

### 타이밍 (15초)
```
[0-2초]  상품명 + 핵심 한 줄 (큰 텍스트, 팝업)
[2-5초]  상품 등장 (배경 제거 + 센터 줌인)
[5-9초]  특징 슬라이드 (AI 카피 2-3줄 순차 등장)
[9-12초] 가격 + 혜택 (할인가, 무료배송)
[12-15초] CTA "지금 바로 구매" + 로고
```

### 모션
- 줌인: 0→100% (0.5초)
- 텍스트: 팝업 등장 (scale 0→1, ease-out)
- 전환: 심플 페이드 (0.3초)
- 이미지: 느린 확대 (Ken Burns, 5% 줌)

### 텍스트
- 폰트: Pretendard Bold / Montserrat Bold
- 크기: 상품명 48px, 카피 36px, 가격 56px
- 색상: 화이트 + 키워드 노란색 하이라이팅
- 위치: 센터 정렬

### 음악
- 스타일: 미니멀 일렉트로닉, 라이트 팝
- BPM: 100-120
- 비트 싱크: 텍스트 등장 타이밍에 맞춤

### 배경
- 단색 그라데이션 or AI 생성 깔끔한 배경
- 색상: 상품 보색 or 뉴트럴 (화이트/그레이/베이지)

## 2. Trendy (트렌디)

### 컨셉
TikTok 네이티브 느낌. 빠른 전환, 트렌디한 효과. Before/After + 트랜지션 패턴.

### 타이밍 (15초)
```
[0-1초]  훅: 강렬한 비주얼 (글리치/줌)
[1-3초]  Before: 일상 장면 or 문제
[3-5초]  트랜지션: 빠른 줌/스핀/글리치
[5-9초]  After: 상품 착용/사용 장면 (멀티앵글)
[9-12초] 특징 + 리뷰/소셜프루프
[12-15초] CTA + 가격 (긴급성 추가)
```

### 모션
- 컷 전환: 1.5초마다 (빠른 리듬)
- 줌 트랜지션: 빠른 줌인→줌아웃 (0.2초)
- 글리치 효과: RGB 시프트 (0.1초)
- 스피드 램핑: 0.5x → 2x → 1x
- 쉐이크: 미세한 카메라 흔들림 (3-5px)

### 텍스트
- 폰트: Pretendard Black / Impact
- 크기: 훅 64px, 카피 40px
- 색상: 네온 컬러 (핑크, 시안, 옐로우)
- 애니메이션: 타이핑 효과 + 바운스
- 위치: 다이나믹 (상/중/하 변경)

### 음악
- 스타일: 트렌딩 사운드, 힙합 비트, EDM
- BPM: 128-140
- 비트 싱크: 모든 컷 전환이 비트에 맞춤 (핵심!)
- 드롭: 상품 등장 시 베이스 드롭

### 배경
- AI 생성 트렌디 배경 (네온, 스트릿, 카페)
- 컬러 그레이딩: 하이 컨트라스트, 약간 틸 + 오렌지

## 3. Luxury (럭셔리)

### 컨셉
미니멀 + 시네마틱. 느린 움직임, 고급 무드. ZARA 스타일 참고.

### 타이밍 (15초)
```
[0-3초]  슬로우 줌인: 상품 디테일 클로즈업
[3-6초]  풀샷: 상품 전체 + 럭셔리 배경
[6-10초] 소재/디테일 클로즈업 (텍스처 강조)
[10-13초] 브랜드 스토리 한 줄
[13-15초] 로고 + 미니멀 CTA
```

### 모션
- 줌: 매우 느린 (3초에 걸쳐 5% 줌)
- 전환: 크로스 디졸브 (1초)
- 이미지: 시네마틱 패닝 (좌→우, 느리게)
- 플리커: 없음 (매끄러운 움직임만)

### 텍스트
- 폰트: Playfair Display / 나눔명조
- 크기: 작고 우아하게 (32-40px)
- 색상: 골드, 화이트, 블랙
- 애니메이션: 페이드인 (0.8초), 하단 정렬
- 레터 스페이싱: 넓게 (5px+)

### 음악
- 스타일: 앰비언트, 피아노, 클래식 일렉트로닉
- BPM: 60-80 (느리게)
- 사운드: ASMR 원단 소리 추가 가능

### 배경
- AI 생성: 대리석, 벨벳, 자연광 스튜디오
- 색감: 로우 새츄레이션, 무드 톤
- 라이팅: 부드러운 하이라이트 + 섀도우

## 4. Cute (큐트)

### 컨셉
귀엽고 발랄. 언박싱/첫인상 패턴. 파스텔 무드.

### 타이밍 (15초)
```
[0-2초]  귀여운 이모지/스티커 + 상품 등장
[2-5초]  언박싱 느낌: 상품 "짠!" 등장
[5-10초] 상품 특징 (귀여운 일러스트/아이콘 + 카피)
[10-13초] 사용 장면 (일상 속 귀여운 연출)
[13-15초] CTA + 하트/별 이펙트
```

### 모션
- 바운스: 통통 튀는 애니메이션
- 스티커/이모지: 화면에 팝업
- 전환: 스위프 (좌→우, 위→아래)
- 반짝임: 파티클 이펙트

### 텍스트
- 폰트: Cafe24 Ssurround / 둥근 고딕
- 크기: 40-48px
- 색상: 파스텔 핑크/민트/라벤더 + 화이트
- 애니메이션: 바운스 + 스케일 (1→1.1→1)
- 이모지 추가: 💕✨🌟

### 음악
- 스타일: 큐트 팝, 일렉트로 팝, 귀여운 효과음
- BPM: 110-130
- 효과음: 팝! 딩! 반짝! 추가

### 배경
- 파스텔 그라데이션
- 일러스트 요소 (구름, 별, 하트)
- 밝고 따뜻한 톤

## 5. Dynamic (다이나믹)

### 컨셉
강렬하고 에너지 넘침. 카운트다운/리스트 패턴. 스포츠/캐주얼에 적합.

### 타이밍 (15초)
```
[0-1초]  임팩트 훅: 큰 텍스트 + 효과음
[1-4초]  포인트 1: 핵심 특징 (번호 + 비주얼)
[4-7초]  포인트 2: 두 번째 특징
[7-10초] 포인트 3: 세 번째 특징
[10-13초] 상품 풀샷 + 가격
[13-15초] CTA + 카운트다운 긴급성
```

### 모션
- 컷 전환: 1초마다 (매우 빠름)
- 줌: 급격한 줌인/아웃 (0.15초)
- 슬라이드: 좌우 빠른 슬라이드
- 스케일: 작게→크게 임팩트
- 쉐이크: 강한 흔들림 (8-12px)

### 텍스트
- 폰트: Impact / Pretendard Black
- 크기: 56-72px (매우 크게)
- 색상: 빨강, 노랑, 화이트 (강한 대비)
- 애니메이션: 슬램 (위에서 떨어지며 등장)
- 번호: 큰 3D 스타일 넘버링

### 음악
- 스타일: 힙합, 트랩, EDM 드롭
- BPM: 140-160 (빠르게)
- 드롭: 매 포인트마다 임팩트 사운드
- 베이스: 강한 808 베이스

### 배경
- 어두운 톤 + 네온/형광 액센트
- 그래픽 요소 (라인, 도형, 패턴)
- 하이 컨트라스트

## 공통 스펙

### 해상도
- 기본: 1080×1920 (9:16, 세로)
- 대안: 1080×1080 (1:1, 인스타 피드)
- 대안: 1920×1080 (16:9, YouTube)

### 프레임레이트
- 기본: 30fps
- 트렌디/다이나믹: 60fps 권장 (스무스 모션)

### 코덱/포맷
- H.264, mp4
- 비트레이트: 8-12 Mbps (고품질)

### 세이프존
- 상단 150px: 플랫폼 UI 여백
- 하단 250px: CTA/캡션 영역
- 좌우 50px: 텍스트 여백
