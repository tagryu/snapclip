- **AI 기반 코디 영상 자동 생성 = 아직 미도입** → 기회
- 📌 학습 포인트: 코디/스타일링 영상 자동화 기회

## 패션 영상 제작 핵심 규칙

### 소재감 전달이 핵심
- 클로즈업으로 원단 텍스처 강조
- ASMR 사운드 (원단 스치는 소리)
- 조명: 자연광 or 부드러운 스튜디오 조명

### 핏감/사이즈감
- 모델 착용 > 플랫레이 (핏감 전달)
- 다양한 체형의 모델 = 반품률 감소
- 사이즈 비교 (S/M/L 착용 비교)

### 스타일링 맥락
- 단품보다 코디 조합이 전환율 높음
- 시즌/TPO(시간/장소/상황) 맥락 제시
- "이렇게 입어보세요" 제안형

### 색감/무드
- 상품 색감에 맞는 배경 색상 매칭
- 시즌 무드 (봄=파스텔, 여름=비비드, 가을=어스, 겨울=모노톤)
- 브랜드 아이덴티티 일관성

## SnapClip 패션 특화 차별점

1. **상품 이미지 → 착용 영상 자동 변환** (경쟁사에 없음)
2. **다양한 체형/피부톤 AI 모델 선택** (포용적 마케팅)
3. **한국 트렌드 템플릿** (무신사/에이블리/지그재그 스타일)
4. **코디 영상 자동 생성** (여러 상품 조합)
5. **소재 클로즈업 자동 생성** (AI 기반 텍스처 강조)
6. **시즌별 배경/무드 자동 매칭**
