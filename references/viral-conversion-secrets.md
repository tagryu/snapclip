## 핵심 발견: 바이럴 ≠ 전환

### 조회수 vs 매출의 진실
- 100만 뷰 영상이 매출 0원인 경우 흔함
- **타겟팅된 10만 뷰 > 비타겟 500만 뷰** (매출 기준)
- TikTok 알고리즘: 구매 의도 있는 댓글이 많은 영상을 더 밀어줌
- "어디서 사요?" "재입고 언제?" 같은 댓글 = 알고리즘 부스트

### 바이럴 vs 전환 영상의 차이
| 요소 | 바이럴 (조회수) | 전환 (매출) |
|------|---------------|------------|
| 목적 | 관심/재미 | 구매 유도 |
| 댓글 | "ㅋㅋㅋ" "대박" | "어디서 사요?" "가격?" |
| 콘텐츠 | 충격/유머/논란 | 실사용/시연/비교 |
| 성과지표 | 뷰/좋아요 | CTR/구매전환율 |

## TikTok Shop 전환 공식 (1,000개 영상 분석)

### 카테고리별 최고 전환 패턴

#### 패션/의류 ⭐
- **최강 패턴**: 다양한 코디 착용 + "이 가격에?" 놀라움
- 여러 색상/스타일 빠르게 전환
- 체형별 핏감 비교
- 📌 SnapClip: AI 모델 다양한 코디 멀티앵글

#### 뷰티/스킨케어
- **최강 패턴**: Before/After + 극적 대비
- 실제 사용 과정 (바르기, 문지르기)
- ASMR 사운드 (발림성 소리)

#### 전자제품/테크
- **최강 패턴**: 저가 vs 고가 비교
- 내구성 테스트 (떨어뜨리기, 방수)
- "이 기능이 $500짜리를 이김" 대비

#### 홈/생활용품
- **최강 패턴**: 문제 → 해결 시연
- 지저분한 상태 → 깨끗한 결과
- 실제 집에서 촬영 (스튜디오 X)

### 7일 후속 콘텐츠 전략 (중요!)
바이럴 영상 1개로 끝내지 않음. 후속 시리즈가 핵심:

```
Day 1: 바이럴 영상 (관심 확보)
Day 2-3: 댓글 응답 영상 (구매 질문 대응)
Day 4-5: 상세 리뷰 / 비교 (구매 결정 지원)
Day 6-7: 사회적 증거 / 리뷰 모음 (최종 전환)
```

📌 **SnapClip 아이디어**: 1개 상품 → 7일 시리즈 영상 자동 생성

## AI UGC 광고의 현재 (2026)

### Topview AI + Sora 2 조합 (143K views 영상)
- 바이럴 영상을 "레퍼런스"로 업로드
- AI가 영상 구조 분석 → 유사한 UGC 자동 생성
- 상품 이미지 + 브랜드 설명 입력
- AI 에이전트가 샷 구성, 스크립트, 편집까지
- **결과**: 진짜 UGC와 구분 어려운 수준

### AI UGC 핵심 요소
1. **자연스러운 말투** — 대본 읽는 느낌 X
2. **실제 사용 장면** — 손에 들고, 피부에 바르고
3. **리액션** — 놀람, 만족, 감동 표정
4. **환경** — 실제 집/방/거리 (스튜디오 X)

### 10가지 메타 광고 크리에이티브 포맷 (86K views, 2026)
1. **UGC/Creator Content** — 여전히 #1 (but "EGC" = 직원 생성 콘텐츠 부상)
2. **Founder Content** — 창업자 직접 출연 (신뢰도 최고)
3. **Before/After** — 극적 변화 (모든 카테고리)
4. **Ugly Ads** — 의도적으로 광고 안 같은 광고 (폰 촬영, 로우파이)
5. **Text-on-Image** — DPA(Dynamic Product Ads) + 텍스트 오버레이
6. **Warehouse/Behind-the-scenes** — 물류센터, 포장 과정
7. **VS/Comparison** — 경쟁사 대비 우위
8. **Negative Marketing** — "우리 제품 사지 마세요 (만약 ~라면)"
9. **AI-generated** — AI 아바타/배경 합성 (급성장)
10. **Compilation/Mashup** — 리뷰/반응 모음

### 핵심 인사이트
> "포맷이 중요하지만, **메시징이 더 중요하다**. 같은 포맷이라도 메시지가 다르면 10x 차이"

## 스토리텔링 전환 공식

### 뇌과학 기반
- 뇌는 **사실보다 스토리를 63% 더 잘 기억**
- "공 찼다" → 운동 피질 활성화 (거울 뉴런)
- 스토리 = 감정 반응 = 구매 결정

### 전환 스토리 구조
```
시작: 관련 문제/상황 제시 (공감)
중간: 발견/변화 과정 (여정)
끝: 결과 + 상품 = 해결책 (전환)
```

### SnapClip 적용
- AI 카피에 스토리 구조 삽입
- "이 니트를 발견하기 전까지 → 겨울 코디가 항상 고민이었어요 → 이제 이것만 있으면 됩니다"
- 감정 키워드: 고민, 발견, 변화, 만족
