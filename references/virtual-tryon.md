# 👤 가상 피팅 / 모델 착용 기술 분석

> Phase 2 핵심 기능 — AI 생성 모델이 상품을 착용한 영상

---

## 기술 현황

### Virtual Try-On (가상 피팅)
- **기술**: Diffusion 모델 기반, 신체 부위별 워핑
- **장점**: 개인화, 반품률 감소 (최대 30%), 재고 없이 미리보기
- **단점**: 주름/드레이프 표현 부족, 부자연스러운 결과물
- **주요 플레이어**: Google Virtual Try-On, Zeekit(Walmart), Vue.ai

### AI 모델 착용 이미지 생성
- **기술**: 이미지 인페인팅 + 포즈 추정 + 의류 워핑
- **현황**: SHEIN이 이미 도입 (상품 이미지 → AI 모델 착용)
- **비용 절감**: 1 look당 $200-2,000 (촬영) → $5-20 (AI)

### 비교
| 방식 | 전환율 | 비용 | AI 자동화 | 핵심 가치 |
|------|--------|------|----------|----------|
| 실제 모델 촬영 | ⭐⭐⭐⭐⭐ | 매우 높음 | X | 최고 품질 |
| AI 모델 착용 | ⭐⭐⭐⭐ | 매우 낮음 | ✅ | 비용 절감 + 확장성 |
| 가상 피팅 (개인화) | ⭐⭐⭐ | 낮음 | ✅ | 반품률 감소 |
| 플랫레이 | ⭐⭐⭐ | 가장 낮음 | ✅ | 제작 용이 |

## SnapClip 구현 방향

### 선택형 옵션 (대표님 요청)
영상 생성 시 사용자가 선택:
1. **플랫레이** — 상품 이미지 그대로 (기본)
2. **AI 모델 착용** — AI가 모델을 생성하여 상품 착용 (프리미엄)
3. **가상 피팅** — 사용자 체형에 맞춤 (Phase 3)

### AI 모델 옵션
- 체형: 슬림 / 보통 / 플러스
- 피부톤: 다양한 톤 선택
- 성별: 남성 / 여성 / 유니섹스
- 포즈: 정면 / 측면 / 워킹 / 캐주얼
- 배경: AI 생성 (스트릿/스튜디오/자연)

### 기술 스택 (검토 중)
- **Gemini 2.5-flash-image**: 이미지 편집 기반 모델 착용 생성
- **Imagen 4.0**: 고품질 이미지 생성
- **외부 API**: Kolors Virtual Try-On, IDM-VTON 등

### 법적 고려
- AI 생성 모델 초상권 → 완전 합성이면 문제 적음
- "AI 생성 이미지" 라벨링 의무화 추세
- 실존 인물 유사 모델 생성은 리스크
