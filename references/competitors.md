# 🏆 경쟁사 분석

> 최종 업데이트: 2026-03-12

## 직접 경쟁사 (상품 영상 생성)

### Creatify — ⚠️ 가장 직접적 경쟁사
- **포지셔닝**: 상품 URL → AI 광고 영상 자동 생성
- **가격**: Free / Starter $19 (20영상) / Pro $49 (40영상) / Enterprise
- **핵심 기능**:
  - URL 입력 → AI 스크립트 + 영상 자동 생성
  - 1,500+ AI 액터 (UGC 스타일 아바타)
  - Meta Top Ads 라이브러리 (10M+ 광고 분석)
  - 광고 클론 기능 (경쟁사 광고 복제)
  - Meta/TikTok/AppLovin 직접 광고 런칭
  - 경쟁사 광고 트래커
- **강점**: 상품 특화 파이프라인, 광고 플랫폼 연동
- **약점**: 실제 촬영 없이 AI에만 의존, **한국어 최적화 부족**, 패션 특화 X
- **SnapClip 차별점**: 패션 특화, 한국 시장, 가상 피팅

### QuickAds — 가상 패션 포토슈트 보유
- **포지셔닝**: AI 광고 크리에이티브 올인원
- **가격**: Free / All-Access $99
- **핵심 기능**:
  - 이미지/영상 광고 자동 생성
  - **가상 패션 포토슈트** (SnapClip과 직접 경쟁)
  - 20M+ 광고 라이브러리
  - ROAS 5.12x 평균
- **강점**: 광고 라이브러리, 데이터 기반
- **약점**: UI/UX 미성숙, 영상 품질 중간
- **SnapClip 차별점**: 더 높은 영상 품질, 한국 시장 특화

### Predis.ai — 소셜미디어 올인원
- **포지셔닝**: 소셜미디어 콘텐츠 생성 + 스케줄링 + 분석
- **가격**: $19 / $40 / $212
- **핵심 기능**: 이커머스 상품 영상/이미지, 소셜 스케줄링, 성과 분석
- **강점**: 올인원 (생성~배포~분석)
- **약점**: 영상 품질 범용적, 패션 특화 X

### Oxolo — ❌ 서비스 종료
- 이커머스 영상 AI 선두주자였으나 AI 미팅 어시스턴트로 피벗
- **시사점**: 시장 공백 존재 → SnapClip 기회

## 간접 경쟁사 (아바타/범용 영상)

### HeyGen — 아바타 품질 최고
- **포지셔닝**: AI 아바타 영상 플랫폼
- **가격**: Free / Creator $29 / Pro $99 (4K)
- **핵심 기능**: Avatar IV, 디지털 트윈, 영상 번역+립싱크, 음성 클로닝, 175+ 언어
- **강점**: 업계 최고 아바타 퀄리티
- **약점**: 상품 영상 특화 아님, 범용 도구

### Synthesia — 기업 시장 장악
- **포지셔닝**: 기업 교육/마케팅 영상
- **가격**: Starter $29 (10분) / Creator $89 (30분)
- **핵심 기능**: 240+ AI 아바타, 160+ 언어, SOC2/ISO42001/GDPR
- **강점**: 기업 신뢰도, 인터랙티브 영상
- **약점**: 이커머스/상품 영상 특화 아님

### Waymark — TV/CTV 광고
- **포지셔닝**: 웹사이트 URL → 브로드캐스트급 영상
- **가격**: Enterprise (커스텀)
- **강점**: 방송급 품질
- **약점**: B2B only, 이커머스 타겟 아님

## 경쟁 구도 핵심 인사이트

1. **패션 특화 AI 영상 서비스 = 없음** → 최대 기회
2. **한국 시장 전용 서비스 = 없음** → 카페24/스마트스토어 연동 시 독보적
3. **Oxolo 퇴장** → 이커머스 영상 AI 시장 공백
4. **아바타 vs 상품**: HeyGen/Synthesia=아바타, Creatify/QuickAds=상품 → SnapClip은 "패션 상품" 특화
5. **Creatify 한국 진출 전 선점 필요** → 속도가 관건
